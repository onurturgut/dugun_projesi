# Velvet Flow pilot assets

- `shineqr-logo-gold.png`: cropped from the existing official project asset at `public/brand/shineqr-lockup-transparent.png`; the source file is unchanged.
- `icon-camera.svg`, `icon-video.svg`, and `icon-gallery.svg`: based on Lucide React 0.575.0 Camera, Video, and Image icons (ISC license), with a presentation circle added around each icon.
- SVG icons use `currentColor` so the Design Center can apply the approved color variant without generating new files.
- `decorative-divider.svg`: project-original Velvet Flow divider. It uses `currentColor`, so the same vector can be reused across all approved color variants without duplicating the asset.
