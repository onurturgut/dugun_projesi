# Düğün Anıları

Aktif uygulama Next.js App Router, MongoDB ve Cloudflare R2 kullanır. Partner işletmeler organizasyon oluşturur; misafirler QR ile yükler; platform yöneticisi, ilgili işletme ve organizasyon sahibi özel albüme erişir. Güncel kurulum, testler ve otomatik silme için [yayın ve işletim rehberini](YAYIN-VE-ISLETIM.md) okuyun. Ürün kararları [gereksinim belgesindedir](PROJE-GEREKSINIMLERI.md).

## Geliştirme

Node.js 22+ ve npm gereklidir. Bağlantı ayarları ve ilk yönetici hesabı için kurulum rehberini izleyin.

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Teknolojiler

- Next.js App Router
- TypeScript
- React
- Tailwind CSS
- MongoDB
- Cloudflare R2
